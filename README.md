A simple Inventory app developed during my CS360 course at SNHU. 
The purpose of this application is to maintain quantity on stock and provide users with quick on-the-go access to current inventory stock, and the ability to add or remove inventory items from the local database. 

The App must have a login screen with authentication, and the main page must be display a list with inventory name and quantity. Features that must be included in the app are the ability to create a user login, the ability to change inventory quantity quickly and easily, as well as adding or removing inventory items.
